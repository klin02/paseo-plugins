File Bridge 在 Windows 本机托管文件助手，通过已有 SSH 密钥与 node030 双向传输文件。Paseo 面板显示电脑名、当前占用者、任务状态、大小和 SHA-256，可取得或释放本机控制权。

同一 node030 账户同一时间只接受一个助手连接。每个任务绑定电脑和连接会话，断线后失败且不自动重放；另一台电脑必须等旧连接结束再接管。这个互斥限于 File Bridge 助手，Paseo Desktop 本身仍可同时连接，原生浏览器工具遵循 Paseo 的独立路由。

需要 Windows 上运行 Paseo 0.13.x 本地 daemon、PowerShell 5.1+、OpenSSH，以及能够非交互登录 node030 的现有 SSH 密钥和已确认的主机指纹。Linux 上安装同一插件可查看控制权和提交任务；Windows 端无需 Python。默认不自动启动，可在面板开启。

每文件上限 32 MiB。Windows 暂存父目录独立于 Linux 源路径；取回文件通过大小与 SHA-256 校验后写入全新目标，拒绝覆盖。可选浏览器执行器接受 node030 排队的标签列表、快照和无选择框上传任务，绑定当前设备与会话，并通过明确配置的 Windows 本地 agent 执行。暂存目录必须位于该 agent 的实际工作区内。隐藏文件输入框还需要本机 Desktop 补丁，插件不会自行修改 Desktop。任务成功只表示输入框已设置，必须另行核对页面处理完成。

插件可读取明确指定的文件并使用本机 SSH，不存储密码、不复制浏览器登录态。浏览器队列不发送聊天消息、不执行任意脚本。已验证 node030 发起上传、Windows 工作区暂存、网页读取真实字节，以及 ChatGPT 准确读取附件随机标记、整数数量和总和。连接与测试聊天保留。两台物理 Windows 轮流接管及原生 Open/Save 窗口仍待验收。
